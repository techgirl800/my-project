## Calculator

Run the calculator with Python 3:

```bash
python3 calculator.py
```

Enter an expression with spaces, such as `12 * 3`. The calculator supports
addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
Enter `q` to quit.

## To-Do List

Run the to-do list with Python 3:

```bash
python3 todo.py
```

Use the menu to add, view, complete, or delete tasks. Tasks are saved in
`tasks.json` in the project folder, so they are still there the next time you
run the program.
